# 踏云寻芳 · 实现约定

> 产品：`docs/功能说明书.md` §3.6；范围：`docs/踏云寻芳.md`；集合：`gallery_posts`。  
> **2026-10-26** 用户点名开做；P2-e 暂缓不挡。

## 目标

已入会成员上传风景/自拍 + 简介 → 互看；作者可删；管理端总览 + 用量（帖数 / 占用 / 容量上限）+ 删帖。

## 不做（首版）

- 点赞 / 评论 / 转发 / 视频 / 访客浏览  
- 云控制台实时配额 API（上限用 `club_profile.galleryStorageQuotaBytes`）  
- P2-e 队伍总览  

## 常量

| 项 | 值 |
|----|-----|
| 简介上限 | 200 字 |
| 单帖 `byteSize` 上限 | 8 MiB（压缩后主图+缩略合计） |
| 作者可见帖上限 | 50 |
| 作者每日发帖上限 | 10 |
| 默认容量上限 | 2 GiB（`2147483648`；未配置时管理端展示用此默认） |
| 云路径 | `gallery/{memberId}/{ts}-full.jpg` / `-thumb.jpg` |

## 权限

| 操作 | 谁 |
|------|-----|
| 列表 / 详情 | `requireViewer`（已绑定） |
| 发帖 / 自删 | `requireBoundMember` |
| 管理端列表 / 删任意 / 改配额 | `admin` / `super_admin` |

## 成员端 API（`memberApi`）

| action | 入参 | 行为 |
|--------|------|------|
| `listGalleryPosts` | `limit?`（默认 30，最大 50） | `visible` 按 `createdAt` 降序 |
| `getGalleryPost` | `id` | 单帖；非 visible → 404 |
| `createGalleryPost` | `imageFileId`, `thumbFileId?`, `byteSize`, `caption` | 校验配额与软上限；写 `visible` |
| `deleteGalleryPost` | `id` | 作者或管理员；软删；尽量删云文件 |

发帖前：小程序可多选图片（**最多 9 张**，`mediaType=image`），逐张压缩并 `wx.cloud.uploadFile`，再分别调 `createGalleryPost`（简介共用；云函数不收二进制）。

## 管理端 HTTP

| 方法 | 路径 | 行为 |
|------|------|------|
| `GET` | `/api/gallery` | `{ list, stats: { postCount, usedBytes, quotaBytes } }` |
| `GET` | `/api/gallery/:id` | 详情 |
| `DELETE` | `/api/gallery/:id` | 强制软删 |
| 配额 | 经 `PUT /api/club` 的 `galleryStorageQuotaBytes` | 俱乐部资料白名单 |

> 产品：`docs/功能说明书.md` §3.6；范围：`docs/踏云寻芳.md`；集合：`gallery_posts`。  
> **2026-10-26** 用户点名开做；P2-e 暂缓不挡。

## 目标

已入会成员上传风景/自拍 + 简介 → 互看；作者可撤回作品 / 删单图；管理端总览 + 用量（作品数 / 图片数 / 占用 / 容量上限）+ 同权限删除。

## 不做（首版）

- 评论 / 转发 / 视频 / 访客浏览  
- 云控制台实时配额 API（上限用 `club_profile.galleryStorageQuotaBytes`）  
- P2-e 队伍总览  

> **点赞已做**（作品级；集合 `gallery_likes`）。

## 常量

| 项 | 值 |
|----|-----|
| 作品题目上限 | 200 字（字段仍为 `caption`） |
| 单帖 `byteSize` 上限 | 8 MiB（压缩后主图+缩略合计） |
| 作者可见帖上限 | 50（按**图片条数**） |
| 作者每日发帖上限 | 10（按**图片条数**） |
| 默认容量上限 | 2 GiB（`2147483648`；未配置时管理端展示用此默认） |
| 云路径 | `gallery/{memberId}/{ts}-full.jpg` / `-thumb.jpg` |
| 单次多选 | 最多 9 张；共用简介与 **`albumId`** |
| 客户端压缩 | 选图 `compressed`；主图最长边 **1920**、缩略 **480**；再 JPEG 质量约 72 / 48；合计超 8MiB 拒传 |

## 作品（album）模型

- 存储仍按**单图一条** `gallery_posts`；同一次发布写入相同 `albumId`。  
- 无 `albumId` 的旧数据：同作者 + 同题目 + 创建时间相差 ≤3 分钟 → 合成一部；否则单帖一部。  
- 列表 / 详情 / 管理端表格均按作品聚合；封面取相册内最早一张；详情弹窗拉齐 `images[]` 临时 URL。

## 权限

| 操作 | 谁 |
|------|-----|
| 列表 / 详情 | `requireViewer`（已绑定） |
| 点赞 / 取消赞 | `requireBoundMember` |
| 发帖 / 续传 / 自删单图 / 撤回作品 | **仅作者**（小程序按钮对非作者隐藏；云函数仍校验作者或管理员） |
| 管理端列表 / 删任意 / 改配额 | `admin` / `super_admin`（按钮对管理员均显示） |

## 成员端 API（`memberApi`）

| action | 入参 | 行为 |
|--------|------|------|
| `listGalleryPosts` | `limit?`；`sort?`=`likes`\|`newest`（默认 `likes`） | 按作品聚合；附 `likeCount` / `likedByMe` |
| `getGalleryPost` | `id`（albumId 或单图 id） | 返回作品（含 `images[]`、赞） |
| `toggleGalleryLike` | `albumId` / `id` | 切换点赞；返回 `{ liked, likeCount }` |
| `createGalleryPost` | `albumId?`, `imageFileId`, `thumbFileId?`, `byteSize`, `caption` | 校验配额与软上限；写 `visible` |
| `deleteGalleryPost` | `id`（单图） | 作者或管理员；软删单图 |
| `deleteGalleryAlbum` | `albumId` / `id` | 撤回整部作品（其下全部可见图 + 赞） |

发帖前：小程序多选图片（**最多 9 张**），生成一次 `albumId`，逐张压缩上传后分别调 `createGalleryPost`（简介与 albumId 共用）。

## 管理端 HTTP

| 方法 | 路径 | 行为 |
|------|------|------|
| `GET` | `/api/gallery` | `{ list: 作品[], stats: { postCount, albumCount, usedBytes, quotaBytes } }` |
| `GET` | `/api/gallery/:id` | 作品详情（albumId 或单图 id） |
| `DELETE` | `/api/gallery/:id` | 删**单张**图片 |
| `DELETE` | `/api/gallery/albums/:albumId` | **撤回**整部作品 |
| 配额 | 经 `PUT /api/club` 的 `galleryStorageQuotaBytes` | 俱乐部资料白名单 |

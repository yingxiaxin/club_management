## 1. 目标与边界

| 项 | 说明 |
|----|------|
| **目标** | 绑定成员打开首页，约 10 秒内看到本周与自己相关的会务，并能跳到 RSVP / 队伍 / 审批 |
| **触达** | 打开即见（会务条角标 + 「本周会务」卡片）；**订阅消息**见 A-c，另开刀 |

**明确不做（本阶段）**

- 管理端出勤看板搬到小程序  
- 全员请假榜 / 全俱乐部任意缺人队广播  
- 第四 Tab、活动关联踏云、评论/精选  
- A-c 未点名前不做订阅消息  

**缺人范围（已定）**：仅 **我创建或我参加** 且状态为 **`recruiting`**、且 `seatsShort = maxMembers - memberCount > 0` 的队伍。

**职责映射（已定）**

| 途径 | 职责 | 缺口文案 |
|------|------|----------|
| 观众 | 奶妈 | 缺N |
| 战士 | T | 缺T |
| 其余途径（含未填写） | 输出 | 缺D |

满编配额（已定）：

| 人数上限 | T | N | D |
|----------|---|---|---|
| 6 | 1 | 1 | 4 |
| 12 | 1 | 2 | 9 |
| 其它 | 1 | 1 | 上限−2 |

相对当前队员途径统计缺口；空位优先补 T → N → D（如 `缺T · 缺N · 缺D×2`）。  
队伍缺口第二行：**队长（途径色）· x/x**（不再展示 `modeName`：建队后该字段默认等于队长角色名，会重复）。

## 2. 信息架构（首页 · 已绑定）

顺序：**品牌区 → 会务条（含嵌入明细）→ 公告 → 踏云 → 今日活动（既有）…**  
**不设**独立「本周会务」区块标题。

### 2.1 会务条（一体）

**顶行**

- 左：身份进「我的」；有待审批时「待处理 N」  
- 右：**日程 · 今日 n · 本周 n** → 活动 Tab  

**下方（有数据才展开，嵌在同一卡片内）**

| 区 | 内容 | 点击 |
|----|------|------|
| 本日/本周活动 | 今日 ∪ 本周（今日优先 + `sortActivities`），最多 **5** 条；**跨日周常容器默认不进本条**（仅当本人有该活动下「开打日=今天」的队伍时，已抬入今日才会出现）；沿用紧迫色/类型标；**两行**：① 名+类型+RSVP ② 时间·阶段 | 活动详情 |
| 队伍缺口 | 见 §1 + T/N/D，最多 **3** 条；卡片间距区分（无分隔线）；**两行**：① 活动名 + 缺口 ② 队长（途径色）· x/x | 队伍详情 |

- 活动与缺口皆空：不展开下方（仅顶行）  
- 有活动但未表态：行上强调「未表态」

## 3. API：`weekHub`

- **权限**：`requireViewer`（已绑定）  
- **云函数**：`memberApi` action `weekHub`  
- **实现**：`cloud/functions/memberApi/weekHubDb.js`  
- **复用**：`activitiesDb.listSchedule`（本周列表与 meta）、`rsvpsDb.listByMember`、`teamsDb.listMyTeams`、`teamsDb.listPendingApprovalsForLeader`（与 `deskDb` /「我的」同口径）

### 返回形状

```text
{
  todayKey,           // YYYY-MM-DD 上海
  weekStart, weekEnd, // { year, month, day } 同 listSchedule.meta
  pendingApprovalCount,
  pendingTeams: [{ teamId, activityId, activityTitle, modeName, pendingCount }],
  activities: [{
    id, title, startText, occurrenceDateKey,
    occurrencePhase, occurrencePhaseLabel,
    myRsvp: 'going'|'maybe'|'decline'|null,
    myRsvpLabel,                // 未表态时为「未表态」
    isToday,                    // 是否上海「今天」本场
    typeLabel, urgencyClass, urgencyIcon, minutesUntil  // 同 listSchedule 装饰
  }],                         // 今日∪本周，今日优先，最多 5
  todayCount, weekCount,      // 顶行「日程 · 今日 n · 本周 n」
  teamGaps: [{
    teamId, activityId, activityTitle, modeName,
    memberCount, maxMembers, seatsShort, myIsLeader,
    shortTank, shortHealer, shortDps,
    roleGapLabel              // 如「缺T · 缺N」或「缺D×2」
  }]                          // recruiting 且 seatsShort>0，最多 3
}
```

首页：`whoami` 后若 `canViewMembers`，与公告/踏云/日程预览并行拉 `weekHub`；下拉刷新一并重拉。

## 5. 验收

1. 绑定成员首页在公告之上可见「本周会务」；本周有活动时显示自己的 RSVP 或「未表态」，点行进活动详情。  
2. 我在招募中且未满的队伍出现在「队伍缺口」，点进队伍详情。  
3. 我任队长且有 pending 申请时，会务条有「待处理 N」，卡片有汇总行，可进「我的」。  
4. 未绑定不展示本周会务。  
5. 部署 `memberApi` 后真机/开发者工具验收。

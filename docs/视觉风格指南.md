# 视觉风格指南（对齐游戏 UI）

> 参考素材：`游戏截图/`（俱乐部列表、俱乐部成员列表、游戏界面）  
> **管理端与小程序共用同一套色彩语义**；各端各自维护 tokens 文件，命名对齐本指南。

## 风格关键词

暗色奇幻 · 哥特/维多利亚金属感 · 半透明深底 · **古铜金**强调 · 奶油白正文

不要做成浅色办公后台；不要用高饱和蓝紫渐变；状态色不要用 Element/Bootstrap 默认艳绿艳红。

## 色板（语义 → 建议值）

| 语义 | Token 名 | 色值 | 用途 |
|------|----------|------|------|
| 品牌/主操作 | `--color-brand` | `#c9a227` | 主按钮、激活态、强调数字 |
| 品牌悬停 | `--color-brand-hover` | `#e0bc4a` | hover |
| 品牌弱底 | `--color-brand-muted` | `rgba(201,162,39,0.16)` | 选中行、nav 激活底 |
| 页面底 | `--color-bg` | `#0e0f14` | 整页背景 |
| 面板 | `--color-surface` | `#1a1c22` | 侧栏、卡片、表格容器 |
| 抬升面 | `--color-surface-elevated` | `#22252e` | 弹层、输入框底 |
| 玻璃面 | `--color-surface-glass` | `rgba(26,28,34,0.92)` | 半透明卡片 |
| 边框 | `--color-border` | `#3a3428` | 分割线、面板描边 |
| 金边强调 | `--color-border-strong` | `#6b5a32` | 重要区块外框 |
| 主文字 | `--color-text` | `#f5ecdc` | 标题、表体 |
| 次文字 | `--color-text-secondary` | `#d4c4a8` | 说明、表头、顶栏 |

| 警告（烛火琥珀） | `--color-warning` | `#d4a04a` | 确认/需注意；比品牌金更偏暖橙 |

| 信息亮 | `--color-info-hover` | `#9ab4c6` | |

另有 `--color-*-glow` 供提示外发光使用（见 `tokens.css`）。

## 形态

- 圆角偏小（`6～10px`），偏「金属面板」而非大圆角卡片
- 阴影克制，可用淡金色外发光代替厚重投影
- 背景可用极弱径向暖光（模仿游戏场景光），避免花哨贴图喧宾夺主
- 表格：深底 + 细金线分隔；hover 行用 `--color-brand-muted`
- 顶部操作提示 / 确认框：暗色面板底；**按状态分色**（左描边 + 图标 + 弱外发光），正文仍用奶油白；字号约 20px、图标约 28px（管理端见 `element-theme.css`）

## 工程落点

| 端 | Tokens 路径 |
|----|-------------|
| PC 管理端 | `admin/src/styles/tokens.css`（+ Element 桥接） |
| 小程序 | `miniprogram/styles/tokens.wxss`（P0-d 已建，色值与上表对齐） |

业务组件禁止写死色值；换肤只改 tokens。

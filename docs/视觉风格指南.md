# 视觉风格指南（对齐游戏 UI）

> 参考素材：`游戏截图/`（俱乐部列表、俱乐部成员列表、游戏界面）  
> **管理端与小程序共用同一套色彩语义**；各端各自维护 tokens 文件，命名对齐本指南。

## 风格关键词

暗色奇幻 · 哥特/维多利亚金属感 · 半透明深底 · **橄榄褐**强调 · 暖奶油白正文  

> 品牌由 `#514529` 提亮至 `#877450`（避开歌颂黄）；实心钮字用深色。

不要做成浅色办公后台；不要用高饱和蓝紫渐变；状态色不要用 Element/Bootstrap 默认艳绿艳红。

### 途径色（职业色板）

色值由产品自 `游戏截图/职业色彩2.png` 提取（窥秘为提亮后实色）。业务页勿写死 hex，用 tokens + 匹配工具（管理端 `admin/src/utils/pathway.ts`；小程序 `miniprogram/utils/pathway.js` / `styles/pathway.wxss`）。

| 途径（含别名） | Token | 色值 | 淡化底 `*-muted` |
|----------------|-------|------|------------------|
| 观众 | `--color-pathway-audience` | `#94c7b1` | 色签弱底 / 小程序 label 用 `*-muted` |
| 战士 | `--color-pathway-warrior` | `#d3742e` | 同上 |
| 歌颂 / 歌手 | `--color-pathway-bard` | `#debd39` | 同上 |
| 学徒 | `--color-pathway-apprentice` | `#2c81b0` | 同上 |
| 占卜 / 占卜家 | `--color-pathway-diviner` | `#54599f` | 同上 |
| 窥秘 / 窥秘人 | `--color-pathway-pryer` | `#975dc1` | 同上 |

用途：管理端 / 小程序列表行 **同款渐变**（细原色条 → muted → 行尾透明）+ 途径色签（管理端途径列、小程序 RSVP 人名）。字段含「观众途径」等亦可匹配。

另有 `--color-*-glow` 供提示外发光使用（见 `tokens.css`）。小程序紧迫度见 `styles/urgency.wxss`。

## 形态

- 圆角偏小（`6～10px`），偏「金属面板」而非大圆角卡片
- 阴影克制，可用淡金色外发光代替厚重投影
- 背景可用极弱径向暖光（模仿游戏场景光），避免花哨贴图喧宾夺主
- 表格：深底 + 细金线分隔；hover 行用 `--color-brand-muted`
- 顶部操作提示 / 确认框：暗色面板底；**按状态分色**（左描边 + 图标 + 弱外发光），正文仍用奶油白；字号约 20px、图标约 28px（管理端见 `element-theme.css`）

## 工程落点

| 端 | Tokens 路径 |
|----|-------------|
| PC 管理端 | `admin/src/styles/tokens.css`（+ Element 桥接） |
| 小程序 | `miniprogram/styles/tokens.wxss`（P0-d 已建，色值与上表对齐） |

业务组件禁止写死色值；换肤只改 tokens。

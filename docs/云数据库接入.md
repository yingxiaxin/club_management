## 导入本地成员（二选一）

### 方式 A：云控制台导入（最快，无需密钥）

1. 本机执行：

```bash
cd cloud/dev-server
npm run prepare:cloud-import
```

2. 打开生成的文件：`cloud/dev-server/data/members-cloud-import.json`（或同内容的 `.jsonl`）  
   > 必须是 **JSON Lines**（每行一条对象）。若报「格式不正确」，不要用带 `[...]` 的数组 JSON。  
   > 若报 `No available bucket`：先在云开发里开通 **存储**，再建桶后再导入。  
3. 微信开发者工具 → 云开发 → 数据库 → **members** → **导入** → 选该文件  
4. 导入成功后，在控制台确认能看到「示例·愚者」「月光馆」「承天慕」等（含 status=left 的历史行也会导入）

### 方式 B：脚本上传（需 API 密钥）

1. 云开发 / 腾讯云控制台拿到 `SecretId` / `SecretKey`  
2. 复制 `cloud/dev-server/.env.example` → `.env`，填写：

```env
DATA_BACKEND=cloud
CLOUDBASE_ENV=cloud1-d6gjqx2kd2f3765f4
CLOUDBASE_SECRET_ID=你的Id
CLOUDBASE_SECRET_KEY=你的Key
```

3. 执行：

```bash
cd cloud/dev-server
npm run import:cloud-members
```

4. 重启 `npm run dev`，健康检查应显示 `"membersBackend":"cloud"`

## 部署云函数 adminApi（小程序/后续正式调用）

1. 微信开发者工具打开本仓库 `miniprogram/`（已配置 `cloudfunctionRoot: ../cloud/functions/`）  
2. 云函数列表找到 `adminApi` → 上传并部署（安装依赖）  
3. 云端测试：`{ "action": "health" }` 应返回 `ok: true`  
4. 列表：`{ "action": "listMembers", "query": { "sort": "powerScore", "order": "desc" } }`

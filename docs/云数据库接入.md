## 导入本地成员（二选一）

### 方式 A：云控制台导入（最快，无需密钥）

1. 本机执行：

```bash
cd cloud/dev-server
npm run prepare:cloud-import
```

2. 打开生成的文件：`cloud/dev-server/data/members-cloud-import.json`（或同内容的 `.jsonl`）  
   > 必须是 **JSON Lines**（每行一条对象）。若报「格式不正确」，不要用带 `[...]` 的数组 JSON。  
   > 若报 `No available bucket`：先在云开发里开通 **存储**，再建桶后再导入。  
3. 微信开发者工具 → 云开发 → 数据库 → **members** → **导入** → 选该文件  
4. 导入成功后，在控制台确认能看到「示例·愚者」「月光馆」「承天慕」等（含 status=left 的历史行也会导入）

### 方式 B：脚本上传（需 API 密钥）

1. 云开发 / 腾讯云控制台拿到 `SecretId` / `SecretKey`  
2. 复制 `cloud/dev-server/.env.example` → `.env`，填写：

```env
DATA_BACKEND=cloud
CLOUDBASE_ENV=cloud1-d6gjqx2kd2f3765f4
CLOUDBASE_SECRET_ID=你的Id
CLOUDBASE_SECRET_KEY=你的Key
```

3. 执行：

```bash
cd cloud/dev-server
npm run import:cloud-members
```

4. 重启 `npm run dev`，健康检查应显示 `"membersBackend":"cloud"`

## 联调排错

### `[100003] Env Not Exists` / `INVALID_ENV`

环境 ID 已与 `cloud/env.json` 一致、密钥格式也正常（`SecretId` 以 `AKID` 开头）时，**多半是密钥所属腾讯云账号 ≠ 该微信云开发环境所属账号**。

微信云开发「设置 → 权限设置」里的 **CLI 密钥不是** `SecretId/SecretKey`，本机 Node SDK 用不上。

按官方账号说明拿密钥（[如何登录腾讯云控制台](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/basis/concepts/account)）：

1. 浏览器打开 [腾讯云控制台](https://console.cloud.tencent.com/)（可先退出当前登录）。
2. 登录方式选 **「小程序 / 公众号」**（不要用随便一个 QQ/微信个人云账号密码）。
3. 扫码后选择已开通云开发的小程序（本项目 AppID：`wx0a3fc7a2aee9f66f`）。
4. 进入 [API 密钥管理](https://console.cloud.tencent.com/cam/capi) → 新建密钥 → 保存 `SecretId` / `SecretKey`（创建时只显示一次）。
5. 可选自检：打开 [云开发环境列表](https://console.cloud.tencent.com/tcb) 应能看到 `cloud1-d6gjqx2kd2f3765f4`；看不到说明登录账号仍不对。
6. 写回本机 `cloud/dev-server/.env`，重启 `npm run dev`，再验 `/api/health` 与成员列表。

控制台能导入、本机 Node SDK 报 Env Not Exists：几乎总是「密钥账号不对」，不是环境 ID 写错。

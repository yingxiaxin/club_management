## 2. 订阅消息与扫码登录环境（👤 + 配置）

正式版用户打开的是 **formal / release**，开发版/体验版配置会对他们失效或收不到提醒。

| 项 | 现在常见值 | 正式公开后应改为 | 在哪改 |
|----|------------|------------------|--------|
| 订阅消息下发环境 `subscribeMiniprogramState` | `trial`（体验版验收） | **`formal`** | 管理端 → **提醒设置** → 下发环境（写入云库 `club_profile`） |
| 管理端扫码小程序码 `CLOUD_QR_ENV_VERSION` | `develop`（本机 `.env`） | **`release`**（正式版码）或长期用体验则 `trial` | 本机 `cloud/dev-server/.env`；若云函数出码则同步云函数环境变量 |
| 云函数 `reminderDispatch` | 已部署 + 定时触发器 | **保持部署**；发版后用正式版点「提醒我」再验一条 | 微信开发者工具上传；云开发控制台看触发器 |

核对清单：

- [ ] 👤 管理端「提醒设置」：**下发环境 = 正式版**，保存成功  
- [ ] 👤 订阅消息**模板仍可用**（未删模板）；模板 ID 仍填在提醒设置里  
- [ ] 💻/👤 `CLOUD_QR_ENV_VERSION=release`（管理员用正式版小程序扫管理端登录码）并**重启**本机 API；云函数侧若配置了同名变量一并改  
- [ ] 🧪 正式版真机：活动「提醒我」→ 到点能收到订阅消息  
- [ ] 🧪 正式版真机：管理端扫码登录（超管/已任命管理员）仍可用  

说明见：`docs/P1-d提醒与订阅消息.md`、`docs/P0-c扫码登录.md`。

## 6. 云函数与部署核对（👤）

正式使用前确认下列云函数为**当前仓库版本**且权限足够：

| 云函数 | 用途 | 注意 |
|--------|------|------|
| `memberApi` | 小程序身份 / 入会 / 列表 / RSVP / 组队 / `expireTeamsDue` | 含 `unbindSelfForTest` 等 |

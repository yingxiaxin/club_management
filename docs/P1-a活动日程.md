# P1-a：活动实例（管理端）

> P1 第一刀。小程序日程 / RSVP / 订阅提醒见后续子阶段。

## 范围

- 云库集合：`activities`（首次访问本机 API 时尝试 `createCollection`）
- 本机 API：`cloud/dev-server/src/cloudActivities.js` + `/api/activities*`
- 管理端：`/activities` 活动 CRUD / 发布 / 取消
- 开始/结束：分量填写（年、月、日、星期、时间）；时间控件步长 5 分钟；活动表区域内部滚动
- **填入今天**：开始/结束旁快捷按钮，一键写入**本机当前**年月日 + 星期几（**不改**时间分量；开始侧点后仍走「开始→结束」联动）
- **新建默认**：开启组队 = 开；立即发布 = 开；**开启提醒** = 开（可关；编辑回填：组队/提醒用活动原值，无「立即发布」）
- **开始→结束联动**：改开始时，结束的年月日星期与开始相同，时间默认开始 +30 分钟（跨日顺延）；编辑回填不覆盖已有结束；结束后仍可手改
- **开启提醒**（开关）：关 → `reminderCycle=none`；开 → 按开始分量自动写周期（完整年月日→`once`；有周几→`weekly`；有日→`daily`；仅时间→`daily`）；无开始时间不可开。`reminderOffsetsMinutes` 活动侧恒为空，**提前量一律读俱乐部提醒设置**

## 到点结束（2026-10-26 增补）

- **一次性**（完整年月日+时间或 `startAt`）：本场结束时刻过后 → 自动 `ended`，并关闭下属仍在招募的队伍（与管理端手动「结束」一致）。由 `teamLifecycle` / `expireTeamsDue` + 小程序读路径 `ensureOneTimeEnded` 触发。  
- **周期模板**（仅周几/每日等）：**保持** `published`；本场结束只换场清 RSVP+队伍（既有 `ensureCycleRollover`）。

## 不做

- **活动模板**（已砍：类型在活动上直接选）
- 小程序今日/本周列表与详情  
- RSVP  
- 订阅消息实际推送与定时触发器（字段已预留）  
- 公告 / 俱乐部资料完善  
- 组队（详情仅预留字段 `enableTeam`）

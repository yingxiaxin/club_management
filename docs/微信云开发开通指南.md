# 微信云开发开通指南（如何拿到环境 ID）

P0 起后端使用**微信云开发（CloudBase）**。环境 ID 常见形如 `cloud1-xxxxx`，配置进小程序后云函数/数据库才指向正确环境。

> **安全**：环境 ID 可以进项目配置；**密钥、私钥、管理员密码不要提交 Git**。

---

## 关键前提（找不到「云开发」多半卡在这里）

官方说明：**测试号不支持云开发**；**游客模式也不行**。必须使用**正式小程序 AppID**。

同时满足：

1. 已安装较新的 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（建议稳定版最新）
2. 项目使用**真实 AppID**（不是测试号、不是「游客」）
3. 当前登录微信是该小程序的**管理员或开发者**
4. 未把云开发权限授权给第三方服务商（若授权过，按钮会灰掉/消失）

---

## 小程序项目该怎么新建（微信开发者工具）

下面两种方式二选一。**目的先开通云开发拿环境 ID** 时，用方式 A 最省事；本仓库成员端代码落在 `miniprogram/` 后，用方式 B。

### 方式 A：云开发 QuickStart（推荐先做，专门用来开通云环境）

1. 打开微信开发者工具，扫码登录（用小程序管理员/开发者微信）。
2. 点 **「+」/「新建」** → 选择 **小程序**。
3. 填写：
   - **项目名称**：随意，如 `club-cloud-setup`
   - **目录**：选一个**空文件夹**（不要直接选本仓库根目录，避免和 Git 文件搅在一起；例如 `D:\临时\cloud-setup`）
   - **AppID**：选你的**正式小程序**（不要测试号、不要游客）
4. 模板/类型里勾选或选择 **「云开发」/「云开发 QuickStart」**（文案因版本略有不同）。
5. 点 **创建**。
6. 进入项目后，点顶部 **「云开发」** → 开通 → 创建环境 → 复制 **环境 ID**。
7. 环境 ID 记下来即可；这个临时项目可以以后不用，真正业务代码仍在本仓库 `miniprogram/`。

### 方式 B：直接对着本仓库的 `miniprogram/`（有代码骨架后）

1. 开发者工具 → **导入** 或 **新建**。
2. **目录**选：`…\俱乐部管理\miniprogram`（只选小程序子目录，不要选整个仓库根，除非工程已改成根目录即小程序）。
3. **AppID** 填正式小程序。
4. 若目录里已有 `project.config.json`，工具会按配置打开；没有则让工具生成一份。
5. 打开后点 **「云开发」**，选择已创建的环境（或新建），与方式 A 拿到的是**同一个 AppID 下的环境**即可。

> 当前仓库若 `miniprogram/` 里还只有 README、没有小程序工程文件，请先用 **方式 A** 开通云开发；等 Agent 初始化小程序骨架后再用方式 B 导入。

### 入口在哪（开通之后）

1. 必须先**打开某个小程序项目**（空白欢迎页没有项目时，往往看不到云开发）。
2. 窗口**顶部工具栏偏左** → **「云开发」**（云朵图标）。
3. 也可试：**菜单 → 工具 → 云开发**（部分版本）。

---

## 开通后

- 控制台首页可见 **环境 ID**，发给开发或写入本地私有配置  
- 首次开通后约 **10 分钟** 云 API 才完全可用（期间可能报 `invalid scope`）  
- MVP 建 **一个** 环境即可  

---

## 环境 ID 用在哪里

| 位置 | 说明 |
|------|------|
| 小程序 `wx.cloud.init({ env })` | 指向该环境 |
| `admin` CloudBase Web SDK | 同一环境 ID |
| 本仓库 `cloud/env.json` | 已记录当前环境 ID；AppID 用本地 `appid.local.json` |

---

## 没有正式小程序时怎么办

1. 打开 [微信公众平台](https://mp.weixin.qq.com/) → 注册**小程序**（个人主体也可先开发；发布能力以微信规则为准）  
2. 注册完成后在「开发管理 / 开发设置」复制 **AppID**  
3. 把你的微信号加成该小程序**开发者**（若不是管理员本人）  
4. 再用 AppID 建项目 → 点「云开发」  

**不能**靠测试号开通云开发（与早期口头方案冲突，以本指南为准）。

---

## 找不到 / 灰色「云开发」排查

| 现象 | 处理 |
|------|------|
| 用了测试号 / 游客模式 | 换成正式 AppID，重新打开项目 |
| 按钮灰色 | 检查是否第三方授权占用云开发：公众平台 → 设置 → 第三方设置 → 解除；重启开发者工具 |
| 不是管理员/开发者 | 让管理员在公众平台把你加成开发者 |
| 工具太旧 / 白屏 | 升级稳定版；仍不行可试重命名插件目录 `WeappPlugins` 后重启（见微信开放社区说明） |
| 看错界面 | 确认打开的是**小程序**项目，不是公众号或纯插件项目 |

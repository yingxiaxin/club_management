# 踏云寻芳（成员晒图）

> **排期**：P2 组队全部做完之后再开；**不挡**正式公开（见 `上线待办.md` §7）。  
> **产品**：`docs/功能说明书.md` §3.6；集合草案见 `docs/数据模型草案.md`（`gallery_posts`）。  
> 开做前另定实现刀（类比 `P2组队.md`）；本文先锁范围，避免被当成「不做」。

## 目标

俱乐部成员上传**游戏内风景截图**或**角色自拍**，附简短简介，供其他已入会成员浏览。  
产品名：**踏云寻芳**（小程序入口展示用此名）。

## 两端能力（已定）

### 小程序 · 成员端

- 已入会成员可**上传图片**并**添加简介**后发布。  
- 其他已入会成员可**浏览他人发布**的内容（列表 / 详情）。  
- 作者可删自己的帖；访客不可看、不可发。

### PC · 管理端

- 可查看**所有成员**发布的内容（总览列表，含作者、简介、缩略图等）。  
- 展示运营指标至少包括：
  - **图片总数量**（有效帖/文件数）
  - **图片占用总空间**（字节合计，发帖时记 `byteSize`）
  - **云服务容量上限**（来自云开发套餐/配额，或配置中的参考上限；实现时对接控制台可读信息或配置项）
- 管理员可删帖（违规清理）；删后空间统计需同步更新。

## 范围（MVP 意向）

| 做 | 说明 |
|----|------|
| 上传图片 | 云存储；客户端压缩后再传（控容量/CDN） |
| 简介 | 短文本；发布时填写 |
| 作者 | 绑定成员的角色名展示 |
| 成员端列表 / 详情 | 看别人的 + 自己发 |
| 管理端总览 + 用量 | 全量帖 + 数量/占用/容量上限 |
| 自己删帖 / 管理员删帖 | 见上 |

## 暂不做（首版）

- 点赞/评论/转发（可后续加）
- 付费相册、外链图床
- 未入会访客浏览
- 视频

## 费用注意

图多会吃云开发**存储 + CDN**；实现须压缩、缩略图、可配单人上传上限。管理端用量面板便于超管提前感知是否接近套餐容量。

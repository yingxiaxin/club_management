## 会话备注（接续必看）

- **勿提交** `.env`、密钥、本地导入数据。  
- P1 顺序：a 管理端活动（已验收）→ b 小程序只读日程 → c RSVP → 提醒/公告。  
- **无活动模板**；类型在活动上直接选。云库残留 `activity_templates` 可忽略。  
- 活动集合首次访问本机 API 时 `createCollection`。  
- 改 `cloud/dev-server` 后须**手动重启** API。  
- 提醒周期规则：无时间→none；年月日+时间→仅 once；日+时间→once/daily；周几+时间→once/weekly；仅时间→daily。提前量默认 10 分钟。  
- 管理员微信测成员端失权不适用（管理权限仍可看名单）。  
- P1-b：小程序读已发布活动；日程匹配需兼容 `startSchedule` 分量（非仅依赖 `startAt`）。

## 本地如何跑

```bash
cd cloud/dev-server && npm install && npm run dev
cd admin && npm install && npm run dev
```

http://127.0.0.1:5173  
登录：票号确认（小程序 `admin-login`）或应急 `superadmin` / `club-change-me`

小程序：开发者工具打开仓库根 → 首页绑定角色名 → 成员列表（编译页选 `pages/index/index`，勿停在 admin-login）。

> `.env`：`DATA_BACKEND=cloud` + `CLOUDBASE_*`（本机已配，不入 Git）。  
> OCR：建议 `pip install rapidocr-onnxruntime`。

## 会话备注（接续必看）

- **勿提交** `.env`、密钥、本地 `data/members.json` / 导入文件。  
- openid **必须用小程序「复制」**，勿肉眼抄（`I`/`l`、`j`/`J` 易混）。  
- 云开发网页控制台看不到未部署函数；部署在左侧文件树右键 `cloud/functions/*`。  
- 云函数出小程序码常遇 `INVALID_WX_ACCESS_TOKEN`；已用手输票号兜底，本机可用 `WECHAT_APP_SECRET` 补码。  
- 成员列表 API 默认隐藏 `status=left`。  
- P0-d 绑定：角色名须与云库完全一致；一人一角，已被绑则 409；验收时编译进 `pages/index/index`。

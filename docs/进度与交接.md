## 本刀实现摘要

| 项 | 路径 |
|----|------|
| users 读写 | `cloud/dev-server/src/cloudUsers.js` |
| 路由 | `POST /api/members/:id/grant-admin`、`revoke-admin`；列表 `accountRole` |
| 管理端 | `admin/src/views/MembersView.vue` 身份列 + 任命/撤销 |
| 应急账号 | `store.js` 读 `.env` 的 `EMERGENCY_*`（真实口令仅本机 `.env`） |
| 小程序 | `miniprogram/pages/index`：「我的身份」可展开扫码登录 / 关联联调 |

API 自测：未关联 → 400；普通 admin → 403；目标超管 → 拒任命/撤销。

## 本地如何跑（接续开发前）

```bash
# 终端 1 — API（默认 :3789）
cd cloud/dev-server && npm install && npm run dev

# 终端 2 — 管理端（默认 :5173）
cd admin && npm install && npm run dev
```

- 打开：http://127.0.0.1:5173  
- 应急账号：`superadmin` / `club-change-me`（或 `admin` / 同密码）  
- **勿把应急密码当生产密码**；上线前必须更换  
- 成员数据文件：`cloud/dev-server/data/members.json`（gitignore，仅本机）  
- 种子模板：`cloud/dev-server/data/seed-members.json`  
- 本机曾测为 **Node 16**，admin 已锁 Vite 4；建议升级 **Node 18+**

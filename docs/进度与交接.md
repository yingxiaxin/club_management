## 本地如何跑

```bash
cd cloud/dev-server && npm install && npm run dev
cd admin && npm install && npm run dev
```

建议（OCR 角色名）：`pip install rapidocr-onnxruntime`

http://127.0.0.1:5173  
账号：`superadmin` / `club-change-me`（开发应急，上线前必改）

> Node 建议 18+；曾用 16 + Vite 4 可跑。改 `dev-server` 后需**手动重启**（无 watch）。  
> 无 RapidOCR 时回退 Tesseract（首次可能下载 `chi_sim`）。  
> 可选腾讯云：见 `.env.example`。
